# New Arrivals Editorial Email

## What will be built
- Add a new **New Arrivals** campaign to the admin message-template area.
- Create an elegant, magazine-style email centered on “Add on to your patio experience.”
- Feature large outdoor-kitchen and sauna photography already approved in the project, without changing product images.
- Include concise editorial copy, featured arrival sections, a consultation action, WhatsApp contact, and the assigned sales representative’s signature.

## Admin sending
- Provide an email preview before sending.
- Keep the existing recipient choices: **All customers** or selected customers.
- Send through the existing bulk-email system so personalization and delivery records remain consistent.
- Show successful and failed delivery totals after sending.

## Technical details
- Add a dedicated reusable HTML email builder with absolute, publicly reachable image URLs and responsive table-based formatting for major email clients.
- Add a focused New Arrivals campaign panel to the existing admin templates screen.
- Preserve the existing Milan campaign, product imagery, quote styling, and product-card outlines.
- Verify the admin controls, rendered email preview, and current build status.
