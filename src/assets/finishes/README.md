# finishes/

Interior pool finish swatches.

- Brand-scoped: gelcoat swatches are **GlimmerGlass-only**; G3/plaster families belong
  to their own brands; Pebble Tec finishes live in `src/data/pebbleTecFinishes.ts`
  (remote CDN URLs from pebbletec.com).
- Never render a finish swatch as the product's main photo — finishes belong in the
  finishes sections only.
