# pavers/

Paver / hardscape material swatches (Belgard, Gloca, travertine, porcelain, Coralina).

- Consumed by the paver selector in Studio, FLIP, 3D deck texturing and quotes.
- Pricing lives in `src/utils/paverPricing.ts`; concrete deck minimum is $10/sqft.
- Textures are authored for 1x1 ft UV mapping so 2D, 3D and quotes stay consistent.
