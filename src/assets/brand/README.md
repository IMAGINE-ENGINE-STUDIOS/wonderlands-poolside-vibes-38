# brand/

Wonderlands logo and wordmark only (`wonderlands-logo.png/.webp`).

- Used for the masthead, FLIP cover wordmark, quote/invoice documents and the
  customer letter.
- **Never** use the logo as a placeholder for a missing product image — layouts must
  fall back to a text-only variant instead.

## Public copy

A public-facing copy of the logo is maintained at `public/logo/` for direct URL access
(e.g., email templates and raw `<img>` tags). When updating the logo, replace both the
source assets here and the public copies in `public/logo/`.
