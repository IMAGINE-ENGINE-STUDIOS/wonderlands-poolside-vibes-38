# water-features/waterfalls/

Rocky waterfall products. These were previously (incorrectly) stored as "pool kits" —
they are waterfall water features, and must never be shown as pool product photography.

Products:

- `maldiveskit-castlerock.*` — Castle Rock waterfall.
- `serenitykit.*` — Serenity waterfall.
- `sunset-grove-kit-pool.*` — Sunset Grove waterfall.

Notes:

- Import the `.webp` variant; the `.jpg` stays as the source original.
- Offered in three tiers with selectable rock color; consumed by the additional-features
  lists in Wonderlands Studio, the FLIP books and the quote configurator, which all read
  the same lookup so imagery and pricing match everywhere.
