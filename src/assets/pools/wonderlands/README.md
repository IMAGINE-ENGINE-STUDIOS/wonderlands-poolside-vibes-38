# pools/wonderlands/ — Wonderlands World Pools

Our own brand: **Wonderlands World** custom concrete (gunite) pools. Built in-house, so
this is the flagship pool category and the one the pool books open on.

Models here:

- `maxima-pool.*` — Maxima, 16' × 40' concrete pool. (Formerly in the short-lived
  `pools/concrete/` folder, which was folded into this brand folder.)
- `madre-perla.*` — Madre Perla, 20' × 40'.
- `pacific-ridge.*` / `pacific-ridge-new.*` — Pacific Ridge (prefer `-new`).
- `wonderpalace.*` — used for the Cape Coral concrete model ($85k, 14' × 28').

Notes:

- Import the `.webp`; `.jpg`/`.png` are the source originals.
- Brand truth lives in `src/data/poolProductLookup.ts` (`brand: "Wonderlands"`) — if a
  model's brand changes there, move its image folder to match.
- Concrete pools use the standard $250/sqft shell base with the 3.5x pool multiplier;
  the Wonderlands Collection cannot be built "on concrete" and is fiberglass-only.
