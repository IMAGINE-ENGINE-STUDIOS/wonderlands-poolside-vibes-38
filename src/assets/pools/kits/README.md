# pools/kits/

Packaged pool kits and standalone marketing models that are not part of a brand's
numbered model line:

- `maldiveskit-castlerock.*`, `serenitykit.*`, `sunset-grove-kit-pool.*` — kit pools.
- `cancun-deluxe.*`, `maxima-pool.*` — standalone models.
- `latham-cape-cod-12.jpg` — Latham Cape Cod 12 photography (replaced a logo
  placeholder that was previously shown for this model).

Import the `.webp` variant where both exist.
