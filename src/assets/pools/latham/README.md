# pools/latham/ — Latham Fiberglass Pools

**Latham Pool Products** fiberglass models (`brand: "Latham"` in
`src/data/poolProductLookup.ts`). Photography must come from latham.com or Latham-supplied
material only — never mix in GlimmerGlass or Wonderlands renders.

Model families present: Apollo, Ariel, Astoria, Axiom (14 Deluxe / 16), Bermuda,
Cancún Deluxe, Cape Cod, Coral, Enchantment (9.17 / 9.21 / 9.24), Fiji, Genesis, Jamaica,
Olympia, St. Lucia, Synergy, Tuscan (11.20 / 13.24 / 14.27), Valencia.

Filename variants per model:

- `<model>.webp` — primary shot for cards and the product book cover (import this).
- `<model>-main` / `-perspective` / `-installed` / `-gallery-N` — extra angles for spreads.
- `<model>-specs` — manufacturer spec / dimension drawing.
- `<model>-optimized` / `-new` — newer or size-optimized re-exports; prefer these.

Notes:

- Cape Cod 12 uses `cape-cod.webp` (the old stray `latham-cape-cod-12.jpg` was deleted).
- Latham spas and tanning ledges live in `../../tanning-ledges/` and the spa data files.
