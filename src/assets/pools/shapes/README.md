# pools/shapes/ — Generic shape / style references

Unbranded illustrative photography used ONLY to explain a shape or style:

- `freeform-beach-entry.*`, `geometric-luxury.*`, `kidney-spa-modern.*`,
  `l-shaped-elegant.*`

Rules:

- Never present these as a named product or attach them to a brand — they carry no
  model identity and would break the brand-scoping rule.
- Fine to use in editorial/index spreads, shape pickers and the drawing-board tutorials.
