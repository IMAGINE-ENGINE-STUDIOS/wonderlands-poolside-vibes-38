# src/assets/solar

Imagery for the **Wonderlands Solar** energy collection (`#solar` on the home
page and the Solar chapter of the FLIP brochure).

| File | Used for |
| --- | --- |
| `solar-roof-array.jpg` | Solar array products, section statement plate, browse/search tiles |
| `solar-battery-wall.jpg` | WonderWall home battery products |
| `solar-pool-heating.jpg` | Solar pool heating system |
| `solar-inverter-charger.jpg` | Wall charger and hybrid inverter upgrade |

Always import these with ES6 imports (`import img from "@/assets/solar/..."`).
Product data lives in `src/data/solarData.ts` — the single source shared by the
main-page section, the FLIP console/brochure and Genius.
