# fencing/

Aluminum fencing imagery and tiling textures.

- `aluminum-fencing.*`, `aluminum-panel-2.*`: panel photography for product tiles.
- `fence-texture.*`: tiling texture used by the 3D scene / drawing board rendering.
- `fence-quote-image.*`: the illustration printed on quotes for fencing line items.
- Pricing is per height tier — see `mem://products/patio-aluminum-fencing`.
