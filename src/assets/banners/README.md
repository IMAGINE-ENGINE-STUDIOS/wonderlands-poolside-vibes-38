# banners/

Wide (≈16:5) hero banners for each main-page section. One per product category.

- Consumed by the main-page category banners, `BrowseCategoriesEditorial` and the
  search menu, which links **strictly to main section banners** (see project rules).
- Naming: `<category>-banner.webp`. Keep the `.jpg` original beside it.
- Also holds cross-brand marketing banners: `latham-gilmer-banner.*`, `pool-banner-2.*`.
