# deck/

Deck and outdoor-living add-on imagery (not pools).

- Pergolas, fire pits, outdoor kitchens, gardens/landscape scenes, hot tubs/spas,
  saunas, lighting, playgrounds, tanning-ledge scenes, CTA art.
- These map 1:1 to additional-feature options in Wonderlands Studio, so the FLIP and
  quote configurators show identical photography for the same feature.
