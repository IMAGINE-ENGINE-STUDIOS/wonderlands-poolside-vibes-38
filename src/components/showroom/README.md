# Showroom tools

Copyright Imagine Engine Studios Corp.

Page-scale tools activate only on explicit Play. One active tool is shared across
the showroom so old studios do not keep rendering or listening to board events.
Close unmounts the tool, not its saved projects. Contained wrappers establish a
fixed-position boundary. Canonical DesignStudio receives embedded and initialView;
SiteBuilder receives embedded, which disables its full-screen layout/control.
showroomPolicy tests enforce launch exclusivity and design-view mapping.
