# 2D Design Studio rules
- 2D Design Studio = PoolBuilder (canonical pool + auto-attached deck) + `designStudio/SiteElementsLayer` (fences/screens/turf drawn on the same board via PoolBuilder's renderOverlay pan/zoom, priced from site lists); switching to 3D rewrites the board3D hand-off from the studio and refuses to show a pool not drawn in 2D — why: one board, 3D always shows exactly the 2D design.
- siteElementsTo3D sends extra pools/spas as Board3D waters with their own attached 2D deck outline and entity-owned finishes; vinyl fences use the vinyl photo with separate panel/post colors, white by default; drawn decks are 3" slabs at 1 ft paver scale; attached decks precede drawn surfaces and earlier same-kind surfaces retain ownership, with water/coping protected by shared net regions; curves bulge outward via curveUtils.outwardBulgeSign (curveFlip per point) — why: 2D and 3D always match.
- 3D Studio extra pools/spas render from a densified ring (BoardElements3D denseRing) so shell, coping, waterline and deck cut share one outline; texture scales default to the main pool (SceneScales); the header pool picker targets any body (activeWater) and the take-off comes from lib/design/board3DTakeoff.ts; Genius edits named bodies via StudioDock geniusTargets — why: every pool behaves like the main pool and costs cover the whole scene.
- Every quote (SurveyQuoteTool) gets line photos via lib/design/sceneQuoteCatalog.quoteLineImage (catalog match beats texture URLs, then same-kind photo, else none; drawn custom pools use CUSTOM_POOL_IMAGE and are concrete builds); waterline is a flat per-body rate (WATERLINE_FLAT_PER_BODY) and per-body tile sizes live on Water3D/Surface3D scale fields — why: quotes match the storefront and every body is editable on its own.
- Pool seating (lounge/bench/corner/sun bench) is procedural ContourSeating (kind field), wall-swept so it bends round corners and wraps up to 360°; only bar stools are discrete chairs; seat footprint is billed at the ledge factor via board3DTakeoff.seatingLines; take-off lines carry the drawn product's own photo (siteElementImage) — why: seats fit any shape and quotes never show unrelated pictures.
