# 2D Design Studio rules
- 2D Design Studio = PoolBuilder (canonical pool + auto-attached deck) + `designStudio/SiteElementsLayer` (fences/screens/turf drawn on the same board via PoolBuilder's renderOverlay pan/zoom, priced from site lists); switching to 3D rewrites the board3D hand-off from the studio and refuses to show a pool not drawn in 2D — why: one board, 3D always shows exactly the 2D design.
- siteElementsTo3D sends extra pools/spas as Board3D waters with their own attached 2D deck outline (4 ft ring only as fallback); vinyl fences use the vinyl photo with separate panel/post colors, white by default; drawn decks are 3" slabs at 1 ft paver scale and the pool's own deck is last in the cut order so nothing overlaps it; curves bulge outward via curveUtils.outwardBulgeSign (curveFlip per point) — why: 2D and 3D always match.
- 3D Studio extra pools/spas render from a densified ring (BoardElements3D denseRing) so shell, coping, waterline and deck cut share one outline; texture scales default to the main pool (SceneScales); the header pool picker targets any body (activeWater) and the take-off comes from lib/design/board3DTakeoff.ts; Genius edits named bodies via StudioDock geniusTargets — why: every pool behaves like the main pool and costs cover the whole scene.
