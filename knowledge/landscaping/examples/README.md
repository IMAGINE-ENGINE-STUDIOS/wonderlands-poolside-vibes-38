# Landscaping example library — index

Reference photographs of professional landscaping that teach Genius what
"great" looks like. Each image is captioned with its style, its key
elements and the lesson Genius should take from it; the compositions are
distilled into reusable recipes in `../landscape-patterns.md`. Genius
consults this library when a guest names a look ("like a Palm Beach
estate") or shows a photo of their own and asks for "something like this".

The founder's direction (2026-10-18) is to grow this library to **hundreds**
of examples. The eight founder-supplied photographs below are the seed set.

## How the library grows

**Adding an image — three steps, always:**

1. **File it** in this folder with a descriptive kebab-case name:
   `<style>-<subject>-<view>.<ext>` — e.g. `tropical-poolside-palm-drift-aerial.jpg`,
   `modern-minimal-rock-bed-ground.jpg`. Style words come from the pattern
   names in `../landscape-patterns.md` where one fits (formal-estate,
   formal-garden, courtyard, waterfront-tropical, promenade, tropical,
   coastal, modern-minimal, topiary). Keep the photograph itself unedited;
   JPG or WebP, landscape orientation preferred.
2. **Caption it** with one new row in the table above: style, the key
   elements a designer would name (structures, water, planting, materials,
   lighting), and one sentence — *what Genius learns* — stated as a
   transferable rule, not a description ("palms in matched pairs frame an
   axis", not "there are two palm trees").
3. **Feed the patterns.** If the photo shows a composition no pattern
   covers, add or amend a pattern in `../landscape-patterns.md` and cite
   the file there. A photo that teaches nothing new still earns its row —
   Genius matches guest photos against this index by caption.

**Caption discipline.** Only what is visible in the photograph: no invented
plant species where the photo doesn't make it certain (say "date-palm
class", "clipped hedge"), no prices, no locations unless the founder
supplies them. One row per image, numbered in arrival order; never renumber
— patterns cite filenames, not numbers.
